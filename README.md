# 재의 서약 (Ashvow)

완전 자유도 높은 한국어 텍스트 기반 브라우저 RPG입니다. 단일 HTML 파일(`free_rpg.html`)로 제작되어 있으며, 별도의 서버나 빌드 과정 없이 브라우저에서 바로 열어 플레이할 수 있습니다.

## 실행 방법

`free_rpg.html` 파일을 다운로드한 뒤 웹 브라우저로 열면 바로 플레이할 수 있습니다. 진행 상황은 브라우저의 로컬 저장소(localStorage)에 자동 저장됩니다.

## 주요 특징

- 10개의 직업(전사, 마법사, 궁수, 도적, 성기사, 마검사, 거너, 네크로맨서, 정령술사, 격투가), 각 직업별 전직·초월 성장 트리
- 10개 지역으로 구성된 세계 지도와 50개 고정 스테이지 캠페인
- 지역마다 배치된 준보스·진보스, 보스별 고유 능력(광폭화, 흡혈, 상태이상 등)
- 고레벨 몬스터의 화상·독·기절 등 상태이상 공격
- 마을 시설: 잡화점(무기·방어구·장신구 구매), 대장간(무기 강화), 음식점, 여관, 온천, 낚시터, 도박장, 투기장, 모험가 길드, 모험 기록(업적)
- 인벤토리, 장비, 스탯 포인트 분배 등 캐릭터 성장 시스템
